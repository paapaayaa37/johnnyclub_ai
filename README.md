# JohnnyClub Neuro — Telegram Mini App с нейросетью (Groq — бесплатно)

Всё уже готово. Groq даёт бесплатный доступ к нейросети без карты — нужно только вставить 2 ключа и один раз задеплоить.

## Что внутри
- `server.js` — сервер, который принимает вопрос от Mini App и отправляет его в нейросеть (Groq)
- `public/index.html` — сам чат, который откроется внутри Telegram
- `.env.example` — сюда вписываете свои ключи

---

## Шаг 1. Получите бесплатный ключ Groq

1. Зайдите на https://console.groq.com
2. Войдите через Google / GitHub / email — карта не нужна
3. Слева откройте **API Keys** → **Create API Key**
4. Скопируйте ключ (начинается на `gsk_...`)

Бесплатный лимит — тысячи запросов в день, для личного бота этого с запасом хватит.

## Шаг 2. Создайте Telegram-бота

1. В Telegram найдите **@BotFather**
2. Отправьте `/newbot`, придумайте имя и юзернейм бота
3. BotFather пришлёт **токен бота** — сохраните его на всякий случай

## Шаг 3. Впишите ключ в проект

1. В папке проекта переименуйте файл `.env.example` в `.env`
2. Откройте `.env` и впишите свой ключ:
   ```
   GROQ_API_KEY=gsk_ваш-ключ
   GROQ_MODEL=llama-3.3-70b-versatile
   PORT=3000
   ```
3. Сохраните файл

## Шаг 4. Запустите локально (проверить, что работает)

Понадобится Node.js (скачать: https://nodejs.org, версия 18+).

В папке проекта выполните по очереди:
```bash
npm install
npm start
```
Откройте в браузере `http://localhost:3000` — должен появиться чат. Напишите вопрос и проверьте, что нейросеть отвечает.

> Локально — это только для проверки. Telegram Mini App требует, чтобы сайт был доступен по **HTTPS в интернете**. Следующий шаг — выложить его в сеть.

## Шаг 5. Разместите сервер в интернете (бесплатно, на Render.com)

1. Зайдите на https://render.com и зарегистрируйтесь (можно через GitHub)
2. Загрузите папку проекта на GitHub (создайте репозиторий и залейте туда файлы):
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. В Render нажмите **New +** → **Web Service** → подключите ваш репозиторий
4. Настройки:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. В разделе **Environment Variables** добавьте:
   - `GROQ_API_KEY` = ваш ключ
   - `GROQ_MODEL` = `llama-3.3-70b-versatile`
6. Нажмите **Create Web Service** и дождитесь деплоя (2-3 минуты)
7. Скопируйте выданный адрес: `https://ваш-проект.onrender.com`

(Альтернативы Render: Railway.app, Fly.io — процесс похожий)

## Шаг 6. Подключите сайт к боту как Mini App

1. Откройте **@BotFather** → `/mybots` → выберите вашего бота
2. **Bot Settings** → **Menu Button** → **Configure Menu Button**
3. Пришлите ссылку на ваш сайт из Render, например `https://ваш-проект.onrender.com`
4. Задайте название кнопки, например «JohnnyClub Neuro»

Готово! В чате с ботом внизу появится кнопка — при нажатии откроется чат с нейросетью прямо внутри Telegram.

## Другие бесплатные модели Groq

В `.env` можно поменять `GROQ_MODEL` на другую (все бесплатные, без карты):
- `llama-3.3-70b-versatile` — самая сбалансированная (стоит по умолчанию)
- `llama-3.1-8b-instant` — быстрее, но попроще
- `qwen/qwen3-32b` — хорошо работает с разными языками
- `openai/gpt-oss-120b` — крупная модель для сложных вопросов

## Если что-то не работает

- **Бот не отвечает / ошибка на сайте** — проверьте, что в Render правильно указан `GROQ_API_KEY` (без пробелов, скопирован полностью).
- **"rate limit exceeded"** — превышен дневной бесплатный лимит Groq, подождите сброса лимита (раз в 24 часа) или уменьшите частоту запросов.
- **Сайт не открывается в Telegram** — адрес должен начинаться на `https://`. Render выдаёт https по умолчанию.

## Как это всё устроено (коротко)

```
Telegram → открывает public/index.html внутри приложения
        → пользователь пишет вопрос
        → index.html отправляет его на /api/chat (ваш сервер)
        → сервер пересылает вопрос в Groq API вместе с вашим ключом
        → ответ нейросети возвращается обратно и показывается в чате
```

Ключ хранится только на сервере — пользователи Mini App его не видят.
